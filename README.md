# 3D Anisotropic Substrate Modeling in Blender

A 3D visualization project showcasing a high-precision, multi-layer **Anisotropic Substrate Structure** designed in Blender. This project bridges engineering concepts with 3D graphics to create a clear structural model.

## Project Overview
This project accurately models a multi-layered substrate system:
* **Silicon Base Layer:** The structural foundation.
* **Aluminum Middle Blocks:** Periodic channels aligned using array and snapping tools.
* **Silicon Dioxide (SiO2) Coating:** A uniform, thin-film protective coating layer.

## Blender Tools Used
* **Extrusion & Scaling:** To build custom shapes.
* **Solidify Modifier:** To give the top coating layer a realistic thickness.
* **Snapping Tools:** For perfect alignment between the different layers.
